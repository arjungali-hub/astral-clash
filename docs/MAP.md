# Where everything lives

Generated by `python art/outline.py --write`. **Do not edit by hand** -
regenerate it. A hand-maintained index of an 11,000-line file is wrong
within a week and worse than nothing once it is.

Anchors are TEXT, not line numbers: search for `function netApplyRemote`,
not for a line that moved three edits ago.

The file is deliberately not split. `art/sync_local.py` keeps the two
builds in step by reading each one end to end, and splitting would retire
that machinery to solve a problem this file solves instead.
